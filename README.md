# 🐍 Learning Python

Welcome to my **Python learning journey**.

This repository documents my journey of learning Python—from understanding the fundamentals to exploring Python's deeper concepts and eventually using it for more advanced applications. I am taking Learning Python by Mark Lutz as a refrence for this repo!

## 📚 What's Inside?

This repository contains my:

* 📖 Notes and summaries
* 🧠 Concept-wise explanations
* 💻 Code examples and experiments
* 🧪 Practice programs
* 🔍 Exploration of how Python works internally

Rather than just collecting syntax, my goal is to understand **what is actually happening behind the code**.

## 🗂️ Learning Approach

I organize my learning primarily by **concepts**, not just chapters.

The idea is simple:

> **Understand the problem → Learn the concept → Experiment with code → Explain it in my own words.**

This makes the repository useful not only for tracking progress, but also for revisiting concepts in the future.
